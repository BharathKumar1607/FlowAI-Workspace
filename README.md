# FlowAI Workspace 🤖

This repository contains the completed Week 1 Task for my Web Development Internship at Yuva. 

## 🎯 Objective
The goal of this project was to convert a provided wireframe concept (an AI Chat Dashboard) into a fully functional, pixel-perfect static web page from scratch.

## 🚀 Technologies Used
* **HTML5**: Semantic structuring (`<header>`, `<main>`, `<aside>`, `<footer>`) for better accessibility and SEO.
* **CSS3**: Custom styling, Flexbox for complex side-by-side layouts, and Media Queries for responsiveness.

## ✨ Key Features
* **Modern Dashboard Layout**: Utilizes CSS Flexbox to create a fixed sidebar and a fluid main chat workspace.
* **Responsive Design**: Adapts seamlessly to mobile and tablet screens (under 768px) by stacking elements vertically.
* **App-like Experience**: The main window is locked to the viewport height (`100vh`), allowing only the chat thread to scroll, mimicking a real software application.

## 🛠️ How to View the Project
Since this is a static web page, no server installation is required. 
1. Clone this repository or download the ZIP file.
2. Navigate to the project folder.
3. Double-click on `index.html` to open it in your default web browser.
